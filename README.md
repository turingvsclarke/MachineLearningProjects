# Machine Learning Projects

Various projects working on Keras, Tensorflow, and Sci-kit learn. These projects were an endeavor to understand the nuts and bolts of machine learning, prior to the widespread use of agentic AI.

These projects use data augmentation and cleaning via Python and Pandas. The data is split into testing and training, which are fed into a fine-tuned model. The predictive power is seen in the accuracy rating of the final performance.
